Implementation

Pure NumPy — No ML Framework

Custom Neural Net Stack
  • LinearLayer: He-initialized weights + per-layer Adam state
  • MLP: 3-layer network with ReLU activations
  • ActorCritic: Shared trunk + two output heads
  • Optimizer: Adam (β₁=0.9, β₂=0.999, ε=1e-8)
  • All ops vectorized with NumPy — no loops in backprop
Behavioral Cloning Warm-Start
  • A HeuristicAgent generates expert demonstrations
  • PPO: cross-entropy loss on expert actions
  • DQN: supervised target Q(s, aexpert) = +1
  • Pre-trains both nets before self-play begins
  • Decouples exploration from learning initially
Self-Play Training Loop
PPO collects 512-step rollout playing Lycanroc
↕ both agents alternate turns in same game
DQN updates after each turn (replay buffer)
↓ every 200 episodes
Evaluate: 50 test games per agent → win rate
↓ if win rate improves > 2%
Save Champion weights

Summary

Key Takeaways

1. Self-Play Works

Two agents with opposing decks improve together through competitive play — no labeled data needed beyond a simple heuristic warm-start.

2. Reward Shaping is Critical

Raw win/loss alone is too sparse. 15 shaped signals — especially the -0.20 end-turn penalty — turn passive agents into aggressive attackers.

3. Pure NumPy is Viable

Full Actor-Critic PPO and Double DQN built from scratch with NumPy. No PyTorch or TensorFlow dependency — every gradient written by hand.

4. PPO vs DQN Tradeoffs

PPO (on-policy) converges to a higher win rate but needs full rollout buffers. DQN (off-policy) updates every turn using replay — faster per-step, lower peak.

5. Legal Action Masking

Masking invalid actions to −∞ before softmax is the single biggest stability win — agents never waste exploration on illegal moves, cutting training time significantly.

6. Playable GUI

Flask web interface makes the trained champions tangible — humans can challenge the PPO champion directly, with real-time board state and energy visualization.
